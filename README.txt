Physics at BSM trial question bank

1. Upload index.html, styles.css, app.js, a1.json and diagrams/ to the root of a static hosting service (e.g. GitHub Pages or Firebase Hosting).
2. Open the hosted index.html URL. Local file:// opening will not load the JSON reliably.
3. Google Sites: Pages > Add > Full page embed > paste hosted URL; or add a normal link/button to hosted URL.
4. This trial saves progress only to localStorage in the current browser; no sign-in or cloud sync.
5. Questions are Draft 2 and require teacher approval.
6. IMPORTANT: No user names, school account data or student information should be collected by this prototype.

Note: The JSON answer field is a zero-based option index (0=A, 1=B, 2=C, 3=D).
